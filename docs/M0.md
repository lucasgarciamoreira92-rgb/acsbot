# M0 — preparação do Mac

Status: **em andamento; aguardando diagnóstico do Mac e primeiro equipamento**.

Base inspecionada: `fc275f42e21b37bc39dc71898db2a519fe1ec89a`.
O teste do navegador com simulador foi confirmado pelo operador. A base contém
painel local, SQLite, chave persistente e agente por pacotes. GenieACS integrado,
reconhecimento de interfaces e fila contínua ainda serão entregues nos marcos
seguintes. A numeração permanece M0–M7 no Mac e M8 para Linux.

## Executar agora

Na pasta do projeto no Mac:

```bash
git pull --ff-only
bash diagnostico-mac.sh
```

O diagnóstico é somente leitura, não requer sudo, não instala dependências,
não abre o navegador e não acessa roteadores. Envie o texto exibido no Terminal
para análise. Ele não lê senhas, chaves, conteúdo do banco ou arquivos de ambiente.
Mostra o IP da interface padrão, que pode ser ocultado ao compartilhar o relatório.
O Docker Engine só é consultado se seu destino efetivo for um socket Unix local.
Cada comando externo tem limite de duração. Não há upload automático do relatório.

Se o projeto estiver em outra pasta, execute os comandos dentro dela. Se o Git
indicar alterações locais ou divergência, preserve-as e envie a mensagem antes
de tentar substituí-las. O diagnóstico também informa se existem alterações locais.

## O que precisamos confirmar

- macOS, arquitetura Intel/Apple Silicon, eventual Rosetta, RAM e espaço livre.
- Node.js para o painel: requisito atual do repositório >=22.13; npm disponível.
- Python do agente >=3.11 e presença do Chromium. A presença não substitui teste real.
- Docker Desktop, Compose e Engine local acessível; recursos da VM do Docker.
- Portas propostas: painel 8787, CWMP 7547, NBI 7557, UI técnica 3000.
  Serviço de arquivos 7567 será opcional. MongoDB ficará interno aos contêineres.
- Primeiro equipamento: fabricante, modelo, firmware, IP/porta/protocolo e acesso
  confirmado pelo navegador do Mac. As credenciais serão cadastradas localmente.
- Mac → interface do equipamento e equipamento → endereço do ACS são caminhos
  diferentes. O segundo será comprovado com um equipamento físico em M2.
- IP reservado do Mac ou DNS resolvível pela rede de gerência; suspensão do Mac
  durante a operação e eventual VPN serão tratados na preparação local.

## Versões e recuperação

A documentação estável consultada em 10/09/2026 indica GenieACS 1.2.16 como
candidato inicial. As versões exatas das imagens Node/MongoDB, seus digests e
compatibilidade com a arquitetura serão fechados após o relatório, antes de
considerar o M0 concluído. Não usar tags `latest` como base reproduzível.

Os requisitos mínimos antigos de Node/MongoDB da documentação GenieACS não são
uma recomendação automática de versões para uma instalação nova. Também será
conferido o suporte do Docker Desktop ao macOS efetivamente instalado.

Antes de modificar a instalação existente em M1, encerrar o painel e copiar a
pasta `.acs-local/data` inteira para backup local, incluindo banco e chave.
Preservar a versão do código acima; nunca substituir a chave de um banco existente.
O diagnóstico não faz essa cópia e não altera o estado dos dados.

Registrar as licenças do GenieACS e dos demais componentes junto das versões
selecionadas. Referências para o fechamento técnico:

- [Instalação oficial do GenieACS](https://docs.genieacs.com/en/stable/installation-guide.html)
- [Projeto e licença do GenieACS](https://github.com/genieacs/genieacs)
- [Requisitos e instalação do Docker Desktop no Mac](https://docs.docker.com/desktop/setup/install/mac-install/)
